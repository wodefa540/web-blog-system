# Web Blog System

## 📌 Project Overview
This project is a simple full-stack blog system designed to practice frontend, backend, and database integration.

## 🎯 Goals
- Learn full-stack development workflow
- Practice API design and data interaction
- Understand frontend + backend communication
- Improve project structuring skills

## ⚙️ Tech Stack (Planned)
- Frontend: HTML / CSS / JavaScript
- Backend: Python (Flask or Django)
- Database: MySQL

## 🧠 Core Features (Planned)
- User registration and login
- Create, edit, delete blog posts
- Display blog list and details
- Basic comment system (optional)

## 🚀 Current Status
Project planning phase (no implementation yet)
